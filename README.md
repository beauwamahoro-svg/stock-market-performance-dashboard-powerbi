# stock-market-performance-dashboard-powerbi
Interactive Power BI dashboard analyzing stock performance (2020–2026) using Python, yFinance, DAX measures, KPIs, and visual analytics.

## Features

- Interactive stock selection slicer
- Top-performing stock KPI
- Total return analysis
- Growth multiple analysis
- Annual closing price trends
- Dynamic filtering across all visuals

## Tools Used

- Power BI
- DAX
- Python
- Pandas
- yFinance
- GitHub

## Key Findings

- NVDA delivered the highest return at 3398.44%
- NVDA achieved a 33.98x growth multiple
- Semiconductor stocks outperformed the broader market benchmark (SPY)
